ArtReads: AI-Powered Art Gallery & Review Platform

A dynamic, full-stack web application designed for art enthusiasts to explore, manage, 
and review artworks. Built with a robust Java backend, it integrates external AI services 
for automated content generation and moderation, all wrapped in a unique, cinematic UI that
adapts its theme based on real-time weather conditions.


Features:

Weather-Adaptive UI: The frontend layout dynamically alters its color palette and 
                     cinematic theme by fetching real-time weather and seasonal conditions
                     via the Open-Meteo API.

AI-Assisted Content Generation: Seamlessly add new artists and artworks with AI automatically
                                generating nationalities, detailed biographies, smart categories,
                                and rich descriptions.

Automated Content Moderation: Utilizes asynchronous AI filtering to actively detect and block profanity,
                               hate speech, and inappropriate language from community reviews and comments.

Secure Role-Based Access: Protected user sessions with strict role-based authentication, alongside dedicated
                          profiles for tracking user-generated art entries and reviews.

Digital Museum Aesthetic: Art pieces are rendered using custom CSS picture frames to simulate a classic,
                           immersive gallery experience.
